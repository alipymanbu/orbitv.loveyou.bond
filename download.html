02 · INSTALL

手机安装四步

从网盘转存到本机，之后就是标准的 APK 安装流程。

转存到自己的网盘

打开页面按钮指向的夸克网盘分享，把里面的 APK 转存到自己的网盘账号下。

下载到手机存储

在夸克网盘客户端里把 APK 下载到手机本地存储。

允许本次安装

在文件管理器里点开 APK，系统会弹「未知来源应用」提示，选择允许本次安装。不同品牌手机入口名称略有差异，一般在设置的「安装未知应用」授权项下。

完成安装并打开

等安装完成即可打开应用，不用注册就能直接进频道列表挑台。

VERIFY

MD5 校验（可选）

在电脑上用 Windows 自带命令算出值，与上面的 MD5 比对即可：

certutil -hashfile 文件名.apk MD5
03 · FIRST RUN

首次启动要做什么

01

不用注册

游客身份就能直接浏览与观看；账号主要面向收藏跨设备同步之类的扩展场景。

02

权限与提示按需处理

首次进入一般会看到权限申请与广告相关提示，按自己的需要选择即可。

03

直接挑台开看

进 All 分区按大洲或主题翻台，或在搜索里按台名、按国家找台，顺手收藏几个常看的。

04 · TV SIDELOAD

装到电视上（Android TV / Fire TV）

电视端优先走应用商店的专门版本；没有商店时可以侧载。

优先装商店专门版

Android TV / Fire TV 有专门版本，通过 Google Play 或 Amazon Appstore 分发，界面布局与手机版不同，且不提供内购升级。

把 APK 弄进盒子

放进 U 盘插到盒子上，或通过局域网把文件传到盒子。

用文件管理器安装

在盒子自带的文件管理器里点开 APK，安装步骤与手机一致。

或者不装，直接投

手机上正在播的频道可以投到同一网络里的 Chromecast 与兼容智能电视上，选台仍用手机操作。

05 · NOTES

看台前的几点提醒

NETWORK

网速与流量

建议下行 10 Mbps 起步；移动流量下信号波动更明显，长时间观看产生的流量费与漫游费由使用者自行承担。

AGE

分级与年龄

安卓商店分级 PEGI 3（全年龄），iOS 分级 16+，服务条款面向 16 岁以上人群；给孩子使用前请自行权衡并陪同。

SOURCES

频道随源变动

开放网络源随时可能下线、迁移或受限，单个台失效稍后再试即可；想要稳定可用的源，往 Personal 里添加自己有权使用的直播源。

VERSION

老机型装不上怎么办

新版持续改进旧设备上的表现；老机型装不上或频繁崩溃时，优先考虑商店的最新版本。
